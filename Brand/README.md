# Adlaire Brand Assets

`Brand/` stores Adlaire-Design brand assets owned by this repository.

The catalog source is `Docs/Brand_Asset_Catalog`.

## Allowed Assets

| Type | Allowed formats | Naming |
| --- | --- | --- |
| Logo | SVG | `adlaire-logo-<name>.svg` |
| Brand image | PNG / WebP | `adlaire-image-<name>.png`, `adlaire-image-<name>.webp` |
| OGP image | PNG / WebP | `adlaire-ogp-<name>.png`, `adlaire-ogp-<name>.webp` |
| Brand-specific icon | SVG | `adlaire-icon-<name>.svg` |
| Brand explanatory asset | SVG / PNG / WebP | `adlaire-brand-<name>.<ext>` |

JPG, JPEG, GIF, PDF, AI, PSD, and EPS are not used.

## Implemented Assets

| File | Role |
| --- | --- |
| `adlaire-logo-primary.svg` | Primary logo. |
| `adlaire-logo-mark.svg` | Small mark. |
| `adlaire-ogp-default.png` | Default OGP image. |
| `adlaire-image-brand-overview.webp` | Brand overview image. |

## Boundaries

- Brand assets are not UI components.
- Official reusable UI icons live in `Icons/` and `Docs/Icon_Set_Catalog`.
- Brand samples may reference these files, but Samples are not the source of truth.
